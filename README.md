# The House Majors

The 22 Major Arcana of Drew Arrowood's house, one likeness per trump, in Crowley's Thoth order (VIII Adjustment, XI Lust). Cards made by Aleister Crowley (a likeness), set v3, November 17, 2026.

## Known errata (from the maker)

- Cameos sit low; the rim touches the numeral on V, XI, XVII and XXI.
- 0: Mozart is in a powdered wig.
- II: the pillars are Greek, not Ur.
- VI: the hermit is missing.
- VII: tiny "U.S." collar insignia.
- IX: no lantern.
- XII: portrait rotated by hand.
- XVII and XX: a modern Earth globe.
